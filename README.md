# Blockchain-Based Certificate Verification System

A decentralized application (DApp) that uses blockchain technology to verify academic certificates and improve their authenticity, transparency, and reliability.

## Features
- Verify certificate authenticity using blockchain records.
- Store certificate verification logic in a Solidity smart contract.
- Interact with the blockchain through MetaMask.
- Deploy and test smart contracts using Ganache.
- Develop and compile smart contracts using Remix IDE.
- Provide a web interface for certificate verification.

## Technologies Used
- **Smart Contract:** Solidity
- **Blockchain Development:** Remix IDE
- **Local Blockchain:** Ganache
- **Wallet Integration:** MetaMask
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Contract Interaction:** Web3/Ethereum-compatible JavaScript libraries

## Project Structure
- `contract.sol` – Contains the Solidity smart contract.
- `contractABI.json` – Stores the contract Application Binary Interface.
- `index.html` – Provides the user interface.
- `script.js` – Handles frontend interactions.
- `server.js` – Runs the backend server.
- `package.json` – Defines project dependencies.

## Setup
Install Node.js, Ganache, and MetaMask. Deploy the smart contract using Remix IDE to your Ganache network, configure MetaMask to connect to that network, update the contract address and ABI if required, install dependencies, and start the application using the script defined in `package.json`.
